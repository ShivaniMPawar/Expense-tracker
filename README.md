# Expense Tracker

A full-stack personal finance web application built with Python Flask and SQLite.

## Features

- Add and delete expenses instantly
- Filter expenses by month
- Monthly budget alert with progress bar
- Spending analytics chart by category
- Input validation on frontend and backend

## Tech Stack

- Backend: Python 3, Flask, SQLite
- Frontend: HTML5, CSS3, JavaScript
- UI Framework: Bootstrap 5
- Charts: Chart.js
- Version Control: Git, GitHub

## How to Run Locally

1. Clone the repository
```bash
git clone https://github.com/ShivaniMPawar/Expense-tracker.git
cd Expense-tracker
```

2. Create virtual environment
```bash
python -m venv venv
venv\Scripts\activate
```

3. Install dependencies
```bash
pip install -r requirements.txt
```

4. Run the application
```bash
python app.py
```

5. Open in browser
```
http://localhost:5000
```

## Key Learnings

- Built REST APIs with Flask
- Connected Python backend to SQLite database
- Input validation on frontend and backend
- Dynamic charts using Chart.js
- Monthly budget tracking with visual alerts
